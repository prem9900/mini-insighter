Mini Insighter (v2)

This is a simple tool that lets you talk to your data.

Instead of writing complex code, you can just ask questions in plain English, like "Show me total sales last month" or "Who are my top 5 customers?".

The AI writes the SQL for you, runs it on your database, and shows you the answer.

What is New in v2

We gave the whole app a premium makeover. It has a professional black-and-white design that feels great to use. We also made it easier to connect your BigQuery data and improved the chat to be smooth and fast.

How to Use It

1. Clone the repo
git clone https://github.com/prem9900/mini-insighter.git
cd mini-insighter

2. Install and Run
npm install
npm run dev

3. Open http://localhost:3000, connect your data, and start asking questions!

It is that simple. Enjoy!
